# Étape 1 — Plan de réalisation

Conception acceptée le 22 novembre 2026. Exécution dans le dossier neuf demandé, sans toucher aux projets voisins.

Objectif : application locale Flask, un profil de démonstration persistant, catalogue Python.

1. Écrire les tests HTTP : pages accessibles, enregistrement et modification du profil, persistance après recréation de l'application, champs invalides refusés sans modifier les données, échappement HTML.
2. Exécuter `.venv/bin/python -m unittest discover -s tests -v` et constater l'absence de l'application.
3. Créer `database.py` (connexion SQLite fermée après chaque opération, table à identifiant unique), `courses.py` (données pédagogiques) et `app.py` (`create_app(test_config=None)` et routes `/`, `/profil`, `/cours`). SQL paramétré, contrôle des longueurs et liste fermée de niveaux côté serveur.
4. Créer les templates Jinja héritant de `base.html`, et `static/style.css` pour une interface française utilisable sur mobile.
5. Relancer les tests ; vérifier aussi un vrai serveur local et son rendu HTML.
6. Documenter lancement, architecture, étapes et scénario dans `README.md` et `docs/DEMONSTRATION.md`.
7. Vérifier les fichiers suivis, enregistrer des commits locaux et créer/pousser un dépôt privé `adaptlearn-ai` si l'authentification GitHub le permet.

Critères de livraison : profil conservé après redémarrage, catalogue consultable sans profil, formulaire invalide sans écriture, aucune IA présentée comme déjà opérationnelle. Les quiz et l'authentification appartiennent aux prochaines étapes.
