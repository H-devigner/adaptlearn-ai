# Étapes 2 à 8 — plan d’exécution

Objectif : compléter le projet pédagogique suivant la conception acceptée et la demande d’exécution de toutes les étapes. Travail sur `feature/version-complete`, publication finale sur main après revue.

Contraintes : français, code Python simple, pas de secrets suivis, sources et mode de génération visibles, aucune fausse affirmation de déploiement cloud ou de validation LLM réelle.

- [ ] Lot A — Contenus et pédagogie (`courses.py`, `pedagogy.py`, tests dédiés) : cinq leçons, quiz éditoriaux à quatre choix, correction pure stricte, parcours par score et prérequis, recommandations et analytics. Vérifier les calculs sans HTTP.
- [ ] Lot B — Recherche et IA (`retrieval.py`, `generation.py`, `ai_service.py`, tests dédiés) : segmentation et TF-IDF, résumé/fiches/quiz locaux, contrat JSON validé pour LLM configurable, erreurs bornées, endpoint de service protégé. Tester avec faux fournisseur HTTP local, aucun appel payant.
- [ ] Lot C — Comptes et stockage (`database.py`, `auth.py`, `app.py`, templates) : UUID, mots de passe hachés, isolation user_id, sessions signées, CSRF, stockage des profils/tentatives/documents/productions. Adapter les tests de l’étape 1 au parcours authentifié. PostgreSQL optionnel.
- [ ] Lot D — Intégration (`learning.py`, `studio.py`, templates) : leçons, quiz, résultats, parcours, ressources, analytics, imports UTF-8/PDF, recherche, productions répondables, téléchargement JSON. Tests de bout en bout HTTP et isolation.
- [ ] Lot E — Exécution distribuée : Dockerfile non-root, Docker Compose avec PostgreSQL et service IA privé, contrôle de santé, tests automatisés CI et guide cloud. Vérifier la configuration et les services réellement disponibles.
- [ ] Lot F — Revue globale, démonstration navigateur, tests complets, mise à jour README et `EXPLICATION_PROJET.md` ; enregistrer et pousser une version identifiée sur GitHub.

Avant chaque implémentation de lot : écrire/exécuter les tests de comportement manquants. Après : exécuter les tests concernés puis revue. Ne pas s’arrêter entre lots pour demander une autorisation déjà donnée.
